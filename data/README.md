# /data

One JSON file per dataset record, conforming to `docs/schema.md`, using only values from `docs/controlled_vocabulary.md`. `/data/adjacent/` holds adjacent-but-out-of-core-scope records (see `docs/scope.md`).

Contains 138 core records as of 2026-07-17 (grew from 132 via a session closing out 4 long-carried `docs/coverage_gaps.md` pan-atlas leads plus 2 open threads found in `sources/query_log.md`, see `docs/changelog.md`), across 19 modalities. See `docs/changelog.md` for the extraction history and `docs/coverage_gaps.md` for what has been searched and not found.
